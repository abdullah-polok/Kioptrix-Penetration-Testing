# Kioptrix Penetration Testing Labs

This repository contains my penetration testing reports for **Kioptrix Level 1** and **Kioptrix Level 2**.

These labs were completed in an intentionally vulnerable environment for educational and penetration testing practice.

## Reports

### Kioptrix Level 1

A complete penetration testing report covering reconnaissance, scanning, enumeration, vulnerability identification, exploitation, and gaining root access.

📄 [View Kioptrix Level 1 Report](./Kioptrix-Level-1/Kioptrix-Level-1-Report.pdf)

### Kioptrix Level 2

A complete penetration testing report covering reconnaissance, scanning and enumeration, SQL injection, OS command injection, reverse shell, local enumeration, and privilege escalation.

📄 [View Kioptrix Level 2 Report](./Kioptrix-Level-2/Kioptrix-Level-2-Report.pdf)

## Tools Used

- Nmap
- SearchSploit
- Metasploit
- Burp Suite
- Netcat
- Linux command-line tools

## Disclaimer

These reports are for educational purposes and were created using intentionally vulnerable lab machines. The techniques demonstrated should only be used on systems where explicit authorization has been granted.
